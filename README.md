# Virtuell Politik (virtuellpolitik.se)

Statisk webbarkiv för *Virtuell politik*, en blogg och essäarkiv av Daniel Wiklander med fokus på politisk teknologi, propaganda, metapolitik och informationskrigföring (2015–2016).

## Innehåll
- `index.html`: Samtliga 12 artiklar i kronologisk ordning med omslagsbilder och sammanfattningar
- `about/`: Presentation och bakgrund
- `2015/`, `2016/`: Enskilda artiklar med fulltext och bilder
- `wp-content/`: Bevarade bilder, typografi och resurser
